# Sales Engineering Tools
Web app built with reactjs on aws.

## Setup and Run
Install:
git
nodejs
VSCode

Clone repo
Open in VSCode

In VSCode"
add AWS Toolkit extension
sign in with IAM credentials, set profile name as default

Open terminal:
npm install
npx ampx sandbox

Open second terminal:
npm run start
